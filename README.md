# HidrataPro

## Descripción

HidrataPro es un prototipo web diseñado para apoyar el seguimiento del consumo de agua durante el día. Permite visualizar las principales pantallas del sistema y navegar entre ellas.

## Tecnologías utilizadas

- HTML5
- CSS3

## Estructura del proyecto

```text
HIDRATAPRO/
│
├── index.html
├── css/
│   └── estilos.css
│
└── paginas/
    ├── regristros.html
    ├── coonsumo.html
    ├── progreso.html
    └── recordatorios.html
```

## Páginas del prototipo

### Inicio

Es la página principal de HidrataPro. Presenta el proyecto y permite acceder a las diferentes opciones del sistema.

### Registro

Permite visualizar el formulario para crear una cuenta de usuario.

### Consumo de agua

Permite seleccionar o ingresar la cantidad de agua consumida durante el día.

### Progreso

Muestra el avance del usuario frente a su meta diaria de consumo de agua.

### Recordatorios

Permite seleccionar la frecuencia y el horario de los recordatorios para consumir agua.

## Navegación

Para iniciar el prototipo se debe abrir el archivo:

`index.html`

Desde la página principal se puede utilizar el menú de navegación para acceder a las diferentes pantallas del sistema.

## Diseño responsive

El prototipo cuenta con estilos adaptables para diferentes tamaños de pantalla, incluyendo computadores y dispositivos móviles.
